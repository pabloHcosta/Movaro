# Movaro

Estrutura inicial do monorepo do produto Movaro.

## Estrutura

- `apps/app`: futura aplicacao Flutter
- `apps/api`: futura API Node.js
- `packages/contracts`: contratos compartilhados entre aplicacoes
- `packages/docs`: documentacao tecnica e arquitetural
- `infra/supabase`: base da infraestrutura de banco de dados

## Status

Este passo cria apenas a fundacao do projeto:

- estrutura de diretorios
- arquivos base de configuracao
- documentacao inicial da arquitetura

Nenhuma stack foi inicializada e nenhuma dependencia foi instalada.
